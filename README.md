# Евгений Любимов — Финансовый консультант

Сайт-визитка финансового консультанта. Полностью статичный, один файл `index.html` — все стили, скрипты и изображения встроены внутрь. Никакого бэкенда или сборки не требуется.

## Структура репозитория

```
.
├── index.html   ← весь сайт целиком (единственный файл)
└── README.md
```

## Как опубликовать через GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него `index.html` (через веб-интерфейс "Add file → Upload files" или `git push`).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

Если хотите открыть сайт на собственном домене — добавьте файл `CNAME` с доменом внутри и настройте DNS согласно [документации GitHub Pages](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).

## Редактирование контента

Весь текст, ссылки и контакты находятся прямо в `index.html` в виде обычной разметки — искать нужные места удобно по русским фразам (например, откройте файл в любом редакторе и найдите текст, который нужно поменять).

Изображения (фото, сертификат, иконки) встроены как `base64` прямо в HTML — чтобы заменить картинку, её нужно перекодировать в base64 и вставить вместо старой строки внутри `src="data:image/...;base64,..."`.
